largest guest function). Native = the whole body (`recomp/kernel/xk_native_70110.c`), every callee (7A960 draw, 80360
x4, 56F20, 11BD0...) and the 40 D3D HLE setters called as the guest calls them. Branch `work/native-70110-20260924`
(worktree `xita-backups/2026-09-18-unified-games/native-70110-wt`), doc `docs/native-70110.md`, work dir
`native-70110-work` (stage = build-x87 copy + host files; stage-n70 = + installer; scripts/gen_core.py + gen_opt.py +

**Method that worked:** generator transliterates the lift into macros; FAST/GEN/DRY instances of one core; static x87
depth -> slots as locals; generator dataflow "dirty since last store" -> minimal SYNC per site; fused fnstsw/test/jcc
branches on cc; frame window + material page one pointer (esp/ebp checked after calls, bail to GEN). Verify = tapped
copy of the guest body (f_00070110_vbody, taps at 72 sites) + native DRY prediction per segment.

**Lessons:** the plain transliteration was only 1.02x on x86 until the per-callee window remap was dropped (1.95x);
lift at -O2 with restrict is already decent. Pi A/B saves far more cycles than instructions (fetch/memory bound).
Makefile counts marker comments (XV_MODEL_*, XV_MATERIAL_SAMPLER_GROUP, ^void f_00070110) - copies of a body must
rename them. xv_preempt's yield on the owner sets eip_hint=[esp]. Walking pad in a30 drops calls to ~20/frame.
