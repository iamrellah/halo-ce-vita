Private invite-only tester server, reworked Sept 18 2026 (started as a public layout the same day).
Owner account "Lord BirchWood". Roles in order: Server Owner, Moderator (kick/ban/timeout/manage
messages+threads/mute/deafen/move/audit log), Tester, Contributor.

**Role gate:** @everyone sees only the Information category. Every other category is private to
Tester, Contributor and Moderator, so a newcomer must be given Tester by hand.

Categories: Information (read-only: welcome-and-rules, announcements, testing-guide, known-issues),
Community (general, off-topic), Voice (General, Dev), Testing (setup-help, bug-reports with pinned
template, performance, test-reports), Builds (read-only: test-builds), Development (Contributor +
Moderator: dev-chat, recompiler, graphics, halo2).

**Loose end:** category order shows Testing above Builds; category drag did not respond.
Not done on purpose: icon/banner, AutoMod, community mode, bots.

**How to apply:** known-issues and testing-guide posts are hand-copied from COMPATIBILITY.md and the
README; edit them when those change. Built via [[desktop-control-x11]].
